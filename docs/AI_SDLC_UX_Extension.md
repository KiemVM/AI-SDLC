# AI SDLC UX Extension

## Slide A - AI Coding ≠ AI Software Development

Current AI frameworks focus on Business, Specification and Engineering, but UX is often missing.

Diagram:
Business -> UX -> Specification -> Engineering

---
## Slide B - UX is the Bridge

Business Goal -> Persona -> User Journey -> User Flow -> Wireframe -> Prototype -> Specification -> Engineering

---
## Slide C - AI UX Workflow (SOC-AI)

Business Goal -> SOC Persona -> Investigation Journey -> Dashboard -> UX Review -> Specification -> Engineering
Outputs: Persona, Journey, Wireframe, Dashboard.

---
## Slide D - Enterprise AI SDLC Reference

Business & Governance (BMAD) -> UX -> Specification (Spec-Kit) -> Engineering (Matt Skills) -> AI Coding Agent -> Security -> CI/CD -> Operations
